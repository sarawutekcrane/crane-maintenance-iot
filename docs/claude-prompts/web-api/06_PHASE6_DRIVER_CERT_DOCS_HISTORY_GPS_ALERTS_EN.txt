=============

OBJECTIVE
=========

Complete supporting operational domains used by Vehicle Detail and later Dashboard.

SCOPE
=====

Driver/Operator:
- master
- contact
- license/certificate
- expiry
- assignment start/end history.

Certificates:
- renewal as new record
- ACTIVE
- REPLACED
- EXPIRED.

Model Documents:
- Load Chart
- Operation Manual
- Service Manual
- revision
- effective date
- storage_ref.

Work History:
- ENGINE_START
- ENGINE_STOP
- PTO_ON
- PTO_OFF
- DEVICE_ONLINE
- DEVICE_OFFLINE
- raw event views
- daily summary views.

Offline event reconciliation:
- event_timestamp
- received_at
- event_id
- sequence_number
- device_id
- created_offline
- time_quality
- duplicate protection
- out-of-order arrival.

History ordering must use event time appropriately, not only received_at.

GPS:
- latest valid location
- event-time location.

Alerts:
- PM due/overdue
- lifetime
- certificate expiry
- repair
- device offline
- inactivity
- sensor/config/OTA/safety alerts
- ACTIVE/ACKNOWLEDGED/MUTED/RESOLVED
- status-based suppression.

Thai UI integration into Vehicle Detail.

ACCEPTANCE TESTS
================

- driver history preserved
- certificate history preserved
- document revisions preserved
- delayed offline event shows actual event time
- duplicate event ingestion is idempotent
- invalid GPS is not shown as valid
- alert mute differs from resolve
- offline alert suppression follows rule
- external file storage reference works.
