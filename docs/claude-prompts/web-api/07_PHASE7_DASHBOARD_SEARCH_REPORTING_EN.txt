=============

OBJECTIVE
=========

Create a practical Thai fleet overview based on existing authoritative services.

SCOPE
=====

Dashboard may include:

- total fleet
- Working
- Ready
- Maintenance
- Out of Service
- Long-term Parking
- engine hours
- PTO hours
- odometer
- online/offline
- last seen
- PM due
- PM overdue
- lifetime parts due
- certificate expiry
- open repair
- inactive vehicle
- GPS
- device/sensor alerts.

Search/filter:

- machine number
- model
- type
- status
- alert
- online/offline
- location when practical.

Reporting views:

- PM due
- open repair
- expiring certificate
- offline device
- lifetime due
- inspection failure.

Performance:
use summary services/endpoints.
Do not scan unnecessary full histories for every card.

Frontend must not recalculate PM/lifetime independently.

Responsive:
desktop, tablet, mobile.

ACCEPTANCE TESTS
================

- summary agrees with underlying services
- filters do not mutate data
- stable links to Vehicle Detail
- Thai labels
- no duplicate PM/lifetime formula
- safe partial/empty states
- reasonable performance with prototype fleet data.

EXIT GATE
=========

Users can find machines and outstanding work without opening Google Sheets.
