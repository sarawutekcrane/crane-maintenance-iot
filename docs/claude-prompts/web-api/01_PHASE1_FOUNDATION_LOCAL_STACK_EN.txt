PROJECT RULES
=============

- All user-facing Web content is Thai.
- Internal API/database codes may be English.
- Web -> Backend API -> Domain/Service -> Repository.
- Web never accesses Google Sheets directly.
- Google Sheets is prototype storage.
- PostgreSQL is future production storage.
- Backend owns authoritative business logic.
- No server/VPS is required for local development.
- Preserve previously accepted frozen contracts.
