OBJECTIVE
=========

Implement scalable parts/lifetime tracking without requiring every physical part to be registered.

SCOPE
=====

1. Part Master.

Tracking modes:
NONE
CONSUMABLE
POSITION_LIFETIME
INSTANCE_TRACKED

2. tracking_start_policy.

3. Part Set / Kit revision.

Requirement types:
REQUIRED
OPTIONAL
ALTERNATIVE

4. Standard parts vs actual parts.

5. PM/Repair actual actions:
CONSUMED
INSTALLED
REMOVED
SERVICED

6. Lifetime rules:
ENGINE_HOUR
PTO_HOUR
ODOMETER
CYCLE
CALENDAR

FIRST_DUE.

7. Model rule + future vehicle override.

8. Do not invent real model/part lifetime rules.

9. On-demand part_instance.

10. Historical prior-usage status:
KNOWN
PARTIAL
UNKNOWN

11. Installation/usage segments.

12. Component-aware counters.

13. Transfer between vehicles without usage reset.

14. IN_REPAIR does not add operating hours.

15. Normal repair does not reset lifetime.

16. Approved overhaul may create new tracking cycle.

17. Preserve old cycles.

18. Thai UI for parts/lifetime/transfer.

ACCEPTANCE TESTS
================

- consumable does not require instance
- position lifetime does not require every serial
- instance can start on demand
- known prior usage is accepted
- unknown remains UNKNOWN
- transfer preserves accumulated usage
- repair pause behaves correctly
- overhaul creates new cycle only with rule
- old cycles remain
- different specifications can use different part IDs
- no preload of every physical part is required.

EXIT GATE
=========

Part tracking grows incrementally with real operational usage.
